# Ritxx Plays

**Music, made personal.**

Ritxx Plays is a personalized music app with a clean interface for discovering music and managing your listening experience. Explore Home, Mix, Library, and Search—all in one place.

## Highlights

- Browse and search music
- Explore mixes and your library
- Use playback and download features available in the app
- Enjoy a personalized Ritxx design

## About this project

Ritxx Plays is an independent customization based on the open-source [SimpMusic](https://github.com/maxrave-dev/SimpMusic) project. It is not an official YouTube or YouTube Music product. Original project credits and license terms are retained.
